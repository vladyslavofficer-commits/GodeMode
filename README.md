# GodMode
Telegram Mini App — терминал подарков MRKT. **Версия 0.1: работающая локальная демонстрация. Реальный MRKT и торговля не подключены.**

## Запуск
Нужен Node.js 22+.
```sh
cp .env.example .env
npm test
npm start
```
Windows PowerShell: вместо cp можно использовать Copy-Item.
Открыть http://127.0.0.1:3000 и нажать «Посмотреть демоверсию». Зависимости npm отсутствуют.

## Что работает
- Русский адаптивный интерфейс, логотип, вход и экран загрузки.
- Проверка Telegram initData на сервере: HMAC SHA-256, срок 5 минут, проверка идентификатора.
- Сессионные токены: случайные 32 байта, срок час; клиент хранит только в памяти.
- Демо-баланс, хранилище, продажи, активные и принятые офферы, история продаж.
- Скидка 1–90%, по умолчанию 10%; расчёты целыми нанотонами.
- Симуляция раз в 5 секунд: оффер → резерв → принятие или отмена → продажа → возврат средств.
- Демо условно моделирует комиссию 5%; это НЕ подтверждённая комиссия MRKT.
- Изоляция состояния по Telegram ID. Демо-гости используют общий учебный профиль.

## Подключение Telegram
1. Создать бота через @BotFather и установить его токен только в серверный BOT_TOKEN.
2. Разместить сервер на HTTPS-хостинге; настроить обратный прокси и HOST=0.0.0.0 в контейнере при необходимости.
3. Установить HTTPS URL как Main Mini App / Menu Button через BotFather.
4. Открыть Mini App из бота и нажать вход. Передаётся initData, а не доверенный объект initDataUnsafe.
Вход в GodMode не даёт доступа к аккаунту MRKT.
DEMO_MODE=false отключает демонстрационный вход и действия; реальных сделок в этой версии нет.

## MRKT: что требуется для следующего этапа
Нужен подтверждённый интерфейс MRKT с разрешённым способом подключения пользователя и документацией:
баланс (доступный/зарезервированный), инвентарь, собственные продажи, свежие листинги с курсором,
флор коллекции/модели, создание и отмена офферов, статус исполнения, выставление на продажу,
комиссии, лимиты, идемпотентность, время жизни и обновление токенов.
mrkt.mjs — контракт, который явно отклоняет вызовы; выдуманных endpoint нет.
Нельзя использовать initData GodMode как авторизацию другого Telegram-бота.
Не передавайте пароли Telegram, коды входа, seed-фразы или токены в issues и коммиты.

## Перед реальной эксплуатацией
Постоянная БД и миграции; шифрование токенов MRKT; блокировки баланса и идемпотентность;
сверка операций после рестартов; обработка отмен, пагинации, задержек API и 429;
контроль свежести флора и правило оценки редких моделей; ограничения риска и аварийная остановка;
журнал операций, мониторинг, резервное копирование и тесты адаптера.
Пока состояние и сессии находятся в памяти и сбрасываются при рестарте. Истории ограничены 100 записями.
При остановке симуляции замораживается весь учебный цикл. Это не семантика остановки будущего живого рынка.
Реальные пополнения и кошелёк не реализованы. Доходность не гарантируется.

## Размещение
GitHub хранит код; GitHub Pages может отдавать статические файлы, но не этот сервер и не круглосуточного воркера.
Для 24/7 нужен VDS или иной постоянный хостинг. GitHub Actions не используется как торговый сервер.
Dockerfile включён; .env и токены не входят в образ.
